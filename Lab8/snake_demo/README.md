# 贪吃蛇游戏

这是一个使用 Python 和 Pygame 实现的经典贪吃蛇游戏。

## 安装依赖

在运行游戏之前，你需要安装 Pygame 库：

```bash
pip install pygame
```

## 运行游戏

```bash
python snake_game.py
```

## 游戏操作

- **方向键 (↑ ↓ ← →)**: 控制蛇的移动方向
- **ESC**: 退出游戏

## 游戏规则

- 使用方向键控制蛇的移动方向
- 吃到红色食物会增加蛇的长度和分数（每个食物10分）
- 蛇不能撞到自己，否则会重置游戏
- 蛇可以穿过边界，从另一侧出现

## 游戏特性

- 蛇身穿墙效果
- 碰撞检测
- 实时分数显示
- 平滑的移动控制
- 经典的贪吃蛇玩法
